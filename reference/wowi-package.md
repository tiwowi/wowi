# wowi: Detect Spatial Clusters of High Rates of Acute Malnutrition

Utilities for detecting statistically significant spatial clusters of
high acute malnutrition rates using a Bernoulli spatial scan statistic,
implemented via the 'SaTScan' software <https://www.satscan.org/>.
